# Screenshots

The main README references these images. Drop PNGs with the following
filenames into this folder to populate them:

| File | Suggested content |
|---|---|
| `home.png` | Home tab — branded landing with globe |
| `apis-tab.png` | APIs tab with an operation expanded (e.g. Open Finance → Get Transactions) |
| `usecases-tab.png` | Use Cases tab showing the about panel + sidebar list |
| `vima-chat.png` | ViMA chat modal open over a use case, mid-edit |
| `config.png` | Config panel showing one of the API sections expanded |

Recommended: capture at 1600×1000, PNG, with the browser chrome cropped out.
