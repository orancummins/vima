## Phase 2 — `./addapi.sh carbon-calculator`

**Status: BLOCKED — by design.**

The portal create-project URL
`https://developer.mastercard.com/create-project/carbon-calculator?services=carbon-calculator`
opens a wizard that *requires* the issuer to enter:

- A valid Mastercard **Customer ID (CID)** (provisioned by Mastercard)
- The issuer's **Legal Name**
- One or more **BIN ranges** (Option 1) or **SenderId** (Option 2.b)

Until those values are obtained the wizard cannot complete and no keys can
be downloaded.

Action for the human:

```
1. Email carboncalculator@mastercard.com (or your Mastercard representative)
   to request Carbon Calculator sandbox onboarding. Provide:
     - Issuer Legal Name
     - BIN range(s) you intend to register (Option 1) or
       SenderId (Option 2.b)
2. Receive back the Customer ID (CID).
3. Open the create-project URL above and submit the wizard with the CID +
   legal name + BIN ranges. Generate signing + encryption keys, download.
4. Add to config/.env:

     CARBON_CALCULATOR_CONSUMER_KEY=<...>
     CARBON_CALCULATOR_SIGNING_KEY_PATH=config/keys/carbon_calculator.p12
     CARBON_CALCULATOR_SIGNING_KEY_ALIAS=<alias>
     CARBON_CALCULATOR_SIGNING_KEY_PASSWORD=<password>
     CARBON_CALCULATOR_ENCRYPTION_KEY_PATH=config/keys/carbon_calculator_enc.pem

5. Remove "carbon_calculator" from DISABLED_API_IDS in apis/catalog.py to
   surface the API in the sidebar.
```
