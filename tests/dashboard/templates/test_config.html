Clean Run — provisioning

Clean Run clones the repo, starts a temporary server on a separate port, provisions fresh SST-* API keys into that server, runs the full test suite, then shuts everything down. Your running app's keys are never touched. Enter your Mastercard Developers credentials here so the browser automation can log in automatically.

Mastercard Developers account
Used only during Clean Run provisioning — never stored in version control.
