How To Use These APIs

🏦 Open Finance — First-Time Setup

Before running Refresh Accounts you need a connected test customer. Follow these three steps in the Open Finance API workbench:

  1. Create Testing User Run the Create Testing User operation — this creates a sandbox customer and saves their customer_id to context.
  2. Generate Data Connect URL Run Generate Data Connect URL. An orange ⋯ button will appear — click it to open the bank connection flow in a new tab.
    For testing, select FinBank and use credentials:
    profile_03 / profile_03
    More test credentials (Mastercard Developers Personas) ↗
  3. Refresh Accounts Once you've completed the bank connection flow, run Refresh Accounts to pull in the connected accounts. This customer will be valid across all Open Finance APIs and Use Cases.
